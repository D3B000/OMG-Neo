# 首页与设置接线（2026-10-21）

本轮保留 Flutter 单窗口结构，复用 OMGLite Python 代码。后续已接入资源浏览与便捷构建，详见 [构建与资源接线](构建与资源接线.md)；便捷关联仍为预览。

## 已接入

- 首页：读取 GIMI / ORFix / TexFx 实际版本，检查 GIMI 更新、下载部署、取消与回退，启动游戏、注入状态与游戏退出监视。版本缺失显示“未检测”，失败显示实际错误，不用计时器制造完成结果。
- 设置：游戏 / GIMI 路径、Hunting / Warning、自动检查更新、更新白名单、启动方法、自定义命令与注入方式、额外 DLL、主题和强调色持久化。原生 Windows 对话框选择目录 / 白名单文件；导入旧 OMGLite 配置时不修改源文件。
- 缓存：显示并清理 Neo 数据根的 cache；不清理 GIMI、Mods 或构建产物。清理前审阅确认，拒绝缓存目录中的 reparse point。
- 配置：400 ms 合并编辑、1500 ms 最大等待；序列化写请求、revision 检查、原子替换、备份恢复。保存失败保留待保存编辑；启动与关闭前 flush。Hunting / Warning 写入 GIMI INI，但保留用户的 `[Loader] launch`。
- 生命周期：一个应用级 Dart 控制器与一个 stdio 后端。切页不启动新进程；关闭时等待取消 / 回退 / 不可取消的启动阶段收尾。后端 stdin EOF 也触发收尾，不结束已经启动的游戏。

## 后端与打包

后端位于 `OMG-Neo/backend/`，开发时直接运行 Python 3.11 x64；发布时 PyInstaller onedir 提供 `omg_backend.exe`、Python 运行库和 loader 资源。发布包无需系统 Python。

本轮为了复用已有 `LaunchController` 和 QThread 信号编排，**保留 PySide6.QtCore**，不加载旧页面、Qt Widgets 或 Qt GUI。这与初稿中“先全面抽离 Qt”的顺序不同：先交付页面业务闭环，QtCore 瘦身另做。后续构建接线已收集 ritual / Cython / UPX / Rust 二进制。

Qt 6.10 使用 Windows 系统 ICU；本机 PyInstaller 会误收 PATH 中不兼容的 ICU 78，打包脚本排除这份冲突副本。当前发布目标为 Windows 10/11 x64。

```powershell
# 在 OMG-Neo/omg_neo 目录
.\build_release.ps1 -Flutter F:\flutter\bin\flutter.bat -Python F:\Python\Python311\python.exe
.\launch.ps1
```

完整输出：`dist/OMG-Neo/`。需分发整个目录。`build_release.ps1` 使用项目内的 Flutter 配置和独立的 `build-home-settings/`，不改全局构建配置，也不覆盖正在运行的旧 Release exe。

开发运行仍可使用 `flutter run -d windows`。未找到随包后端时，客户端从项目父目录查找 `backend/main.py`。可用 `OMGNEO_PYTHON` 指定开发解释器；发布版本优先使用 exe 同目录的冻结后端。

默认数据目录为发布包内 `dist/OMG-Neo/AppData/`，配置是其中的 `config.json`，构建工作区是 `build-work/`。测试 / 独立运行仍可显式指定 `OMGNEO_DATA_ROOT`。本机原 C 盘数据已校验迁移，详见 [应用内数据目录](应用内数据目录.md)。旧 Lite 的配置需手动导入，不修改源文件。

## 验证边界

后端集成测试使用临时 GIMI 和本地 HTTP 更新包，覆盖配置与 INI、白名单保留、启动预检失败、检查取消和 EOF 退出；不联系远端或启动真实游戏。冻结后端另在移除 Python PATH、清空 PYTHONPATH、任意工作目录的环境验证握手和配置读写。Flutter 测试覆盖实际版本显示、设置保存和切页保持、保存失败阻止启动、取消等待真实终态及原有 UI 回归。

```powershell
# 从 OMG-RE 根目录
python -m unittest discover -s OMG-Neo/backend/tests -v

# 从 OMG-Neo/omg_neo 目录
flutter analyze
flutter test

# 发布包的实际 Dart → 冻结后端通信验证（临时配置目录）
dart tools/smoke_backend.dart dist/OMG-Neo/backend/omg_backend.exe
```

首轮验证未执行真实游戏注入与远端更新；后续已按用户授权补验，详见 [2026-10-21 实机验证记录](实机验证-2026-10-21.md)。原生路径对话框已编译进入 Windows runner；其返回值由设置草稿提交到同一个配置服务。

本轮协议是首页 / 设置所需的最小实现；尚未实现设计文档中的持久任务日志、事件重放、通用任务进程池与跨实例窗口激活。后端数据根有独占锁；重复进程会报告占用，不允许两个后端同时写同一配置。
