# 模态弹窗中的 UI 调整

- F8 改为由窗口内的键盘事件监听处理，不再依赖主页面的焦点树。应用内模态弹窗打开、输入框获得焦点时仍可使用；带修饰键的组合不触发。
- 截图边界移到 Navigator 上方，原图和批注图包含当前弹窗、遮罩以及背景页面，保持窗口逻辑尺寸及组件坐标一致。
- 同一时间只允许一个调整工具，包括截图尚未完成时连续按 F8 的情况。关闭工具返回原弹窗，保留输入与原有交互。
- 监听随页面销毁解除；Release 默认继续关闭调整工具和截图边界。

验证：静态检查无问题，47 项 Flutter 回归通过（另 2 项按条件跳过）；Release 配置的独立测试通过。新增验证覆盖浅、深主题、弹窗输入焦点、截图像素包含弹窗、重复按键、保留输入及销毁后监听清理。原有框选、PNG/JSON 导出回归也通过。
