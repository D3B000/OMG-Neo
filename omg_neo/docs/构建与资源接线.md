# 便捷构建与资源浏览（2026-10-21）

Flutter 两页接入同一个 stdio Python 后端。正式入口传入 NeoController；不传控制器的 NeoApp 保留为界面测试预览。

## 便捷构建

- 刷新源码版本、下载源码、源码预处理、MSBuild 环境检测与编译、蓝奏云批次下载，复用 Lite alchemy。源码下载使用后端保存的 release，不接受前端任意下载地址。
- 包装、涂装 Python、涂装 Rust 使用随包 ritual_bundle.pyd、Cython、UPX、Rust DLL。构建入口新增编译导出 bundle.run_build，运行态不导入私有源码。缺少组件时禁用对应执行按钮。
- 选项保存在 Neo 数据根 build-options.json；工作区是 build-work，包含 project、cloud、artifact、output、input、temp。不复用或清理旧 Lite 工作区。
- 成功产物登记到 build-products.json：来源、路径、SHA-256、时间。失败先注销对应产物；自动化仅在上游成功后继续。复制前校验哈希，拒绝未登记或已变化的旧 DLL。
- 支持构建后执行仪式、完成后复制到 GIMI。复制前检测游戏进程；运行中拒绝替换。原 DLL 备份到 dll-backups，同目录临时文件复制完成后替换。
- 清理显示真实项目、批次、产物及大小，勾选确认后执行。后端仅接受扫描生成的 ID，复核指纹，拒绝过期计划、越界、链接及联接目录，逐项报告失败。范围仅为 Neo 的 build-work。
- 下载可中断；MSBuild 和仪式等待当前阶段收尾，取消阻止后续自动化。任务和日志保存在应用级控制器，切页不丢失。日志可导出到 Neo 数据根 logs。

## 资源浏览

- 根目录为设置中的 GIMI/Mods，显示物理直接子目录、面包屑和当前目录名称搜索。正式目录没有写死“角色 / 武器 / 怪物 / 其它”，没有启用自动分类。
- 直接含 INI / modinfo 的目录和松散 INI 显示为模组，其它目录显示为文件夹；模组卡片保留进入子目录的按钮。缩略图、切换键复用 Lite 识别器。图片和切换键点击不触发启停。
- 启停调用 set_mod_enabled，实际重命名 DISABLED 前缀，使用返回的新路径重建列表和 ID。请求携带 revision，拒绝失效句柄。GIMI 目录变化后重新加载；游戏内需按原有方式重新加载。
- 写回固定针对整个 Mods，读取 GIMI/d3dx_user.ini，不随面包屑缩小范围。延续旧规则：跳过文件名含 DISABLED 的 INI；停用目录内的其它 INI 仍参与。
- 写回前备份全部候选 INI 到 resource-backups/时间-ID，然后调用旧 write_back_swapkeys。报告展示逐文件日志、实际变化数量、失败和备份位置；部分失败不显示为全成功。这不是跨文件原子事务。
- 资源路径在逻辑上限制为 Mods 内的入口，支持目录 junction / 符号链接指向外置存储。循环链接不递归，写入前核对链接目标，junction 启停只重命名入口。构建清理仍拒绝链接和联接目录。各类任务共用后端任务锁。

## 发布

```powershell
.\build_release.ps1 -Flutter F:\flutter\bin\flutter.bat -Python F:\Python\Python311\python.exe
.\launch.ps1
.\launch.ps1 -Resources
```

分发整个 dist/OMG-Neo，包含 backend，无需系统 Python。仪式组件位于 backend/_internal/resources/binaries/ritual；开发组件位于 OMG-Neo/backend/vendor/ritual。私有源码仍留在 OMGLite-ritual。
