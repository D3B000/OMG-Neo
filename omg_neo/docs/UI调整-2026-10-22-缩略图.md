# 缩略图与图片预览

落实 resources-1792673574031.json 的“缩略图的质量太低了”批注，原始批注归档在 design-reviews/2026-10-22-thumbnail/。

- 84×84 卡片使用最高 252×252 的等比例解码预算，即使 Windows 为 100% 缩放也保留更多细节；预览弹窗使用最高 900×480 的等比例解码预算。缩略图和预览采用高质量采样，保留现有遮罩行为。
- 继续限制图片缓存和渲染缓存各 16 MiB，不直接缓存全分辨率大图。极端长图仍在双维度预算内解码；原始图片本身的清晰度不会被改变。
- 预览弹窗“关闭”左侧新增切角“打开图片”按钮，适配浅、深主题。没有预览图或后端不可用时禁用；关闭按钮始终可用。
- 点击后由 resources.openImage 根据当前资源句柄和列表版本找到预览原图，再使用 Windows 默认图片关联程序打开。图片缺失、句柄过期、系统关联失败会显示提示；不会关闭预览弹窗或切换资源启用状态。

验证：静态检查无问题；46 项 Flutter 回归通过，另 2 项按条件跳过；50 项 Python 测试通过；Release 隐藏调整工具的单独测试通过；打包后端通过 9 项 stdio 集成验证，包含新增图片接口的过期句柄校验。图片解码验证覆盖 1000×1500 原图在 100% 缩放下解码为 168×252，以及 100×5000 长图的内存上限。浅、深弹窗截图见 shots/image-preview-light.png、shots/image-preview-dark.png。

完整分发目录：dist/thumbnail-quality-20261022/OMG-Neo-v0.0.1-debug/ 和 dist/thumbnail-quality-20261022/OMG-Neo-v0.0.1/。Debug 保留 UI 调整工具，Release 关闭 UI 调整工具；均包含后端和注入子进程，不携带旧配置、日志或 AppData。
