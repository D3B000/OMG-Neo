# 服务器切换与备份面板

落实 qt-analysis-stability-20261025 调试包中的两份批注：serverSwitch-1792946026374.json、serverSwitch-1792946451204.json。原始批注与截图归档于 design-reviews/2026-10-26-server/。

- 服务器切换页左侧为目标服务器、检查／切换／恢复操作与状态，右侧为本地和替换包的版本、版本声明及资源说明。版本不一致使用当前强调色提示，长构建号和错误说明可以换行。
- 备份页左侧为游戏目录、输出目录及备份按钮，右侧为备份说明。按钮高度从 48 调整为 36，路径和原有备份业务保留。
- 两栏分别滚动，内容区结束于底部导航栏上方；窄窗口回到单列滚动。导航栏位置保持不变。
- 顶部新增“打开目录”，由 serverSwitch.openDirectory 打开当前应用数据目录中的 server-switch 文件夹，不存在时创建。可在任务期间打开，不执行游戏检查或切换；失败时在操作状态区域显示原因。
- 切换、备份和恢复任务统一使用首页同款分段进度条，紧贴窗口最底边，显示任务真实进度和状态；未知进度沿用首页连接状态，结束／失败／取消时隐藏，不占用面板空间。
- 为标题操作、功能面板、版本、说明、状态和底部进度添加稳定的 UI 批注区域。
