# UI 与功能调整 / 2026-10-22

依据 split-service 调试版导出的 5 份批注，原始记录归档在 design-reviews/2026-10-22/。

- 资源浏览：面包屑右端依次为打开当前目录、当前目录所有文件夹、当前目录 INI 文件。后两项在右侧弹出可滚动菜单；文件夹跳转目录，INI 使用系统关联程序打开。列表只包含当前目录的直接子项，不受搜索或空文件夹过滤影响，也不使现有卡片句柄失效。菜单读取后若已经换目录，丢弃过期结果。
- 面包屑：分隔箭头改为不可点击的紧凑图标，末尾不再显示箭头；长路径可横向滚动。移除原先单独占行的当前目录说明，将打开目录图标移到新增图标左侧，让资源区获得更多空间。
- 便捷关联：顶部切换“目录联接 / JUNCTION”和“递归包含 / INCLUDE”，每次只显示当前功能。左侧为输入和操作，右侧为说明与配置预览。切换功能时保留各自输入及结果，离开再返回保留当前标签与输入；执行期间禁止切换，原有检查与创建业务继续使用。
- 便捷构建：顶部新增“工作目录”，打开当前应用管理的 build-work；任务运行期间仍可打开。终端行间距收紧，新输出始终滚动到末尾，包括用户此前向上翻阅、换行导致滚动范围变化、日志达到保留上限等情况。
- 成功通知：仪式显示“执行完毕”，复制显示“复制完毕”，构建显示“构建完毕”；完整路径、备份位置继续保留在终端。失败和取消保留原始信息，不显示成功提示。同类任务连续成功仍能分别提示。

新增后端方法：resources.directory（只读目录菜单）和 build.openWorkspace（打开管理目录，不执行构建）。

验证：Flutter 静态检查无问题；38 项 Flutter 测试通过（另 2 项按运行条件跳过）；46 项 Python 测试通过；打包后端通过 9 项 stdio 集成验证。包含临时目录的文件夹／INI 筛选与句柄有效性、资源接口 stdio 调用、工作目录打开目标、关联分页保留表单、终端末尾跟随及成功／失败通知。
