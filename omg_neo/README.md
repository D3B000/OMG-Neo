# OMG-Neo Flutter UI

Windows 桌面 UI 原型，默认 960 × 540 逻辑像素，支持放大窗口。
首页与设置已通过 stdio 接入复用 OMGLite 的 Python 后端：真实配置、组件版本、GIMI 检查 / 更新 / 取消、游戏启动与注入状态，以及设置保存、路径选择、白名单、缓存和外观。资源浏览与便捷构建已接入 Python 服务。
完整说明见 [首页与设置接线](docs/首页与设置接线.md)。

当前接线版：`dist/OMG-Neo/omg_neo.exe`，`launch.ps1` 指向此版本。需分发完整目录与 backend，用户无需安装 Python。配置保留在该目录的 AppData 内，旧发布包保留在 dist 中。
## 运行

```powershell
flutter pub get
flutter run -d windows
# 启动主界面并选中浏览页（兼容原参数）
flutter run -d windows -- --resources
# 构建包含后端的发布包，再运行
.\build_release.ps1
.\launch.ps1
```

发布时请一起分发整个 Release 目录（包含 data 和 DLL），不能只复制 exe。
`launch.ps1` 可启动编译好的主界面；`launch.ps1 -Resources` 启动主界面并选中浏览页。

## 界面

- 首页：GIMI / ORFix / TexFx 实际版本、检查 / 更新 GIMI、取消任务、启动游戏与状态提示。
- 主导航：首页 / 浏览 / 工具 / 设置。
- 工具：便捷构建、便捷关联路径表单。
- 浏览：整合在主界面，仅保留文件夹模式；页头居中搜索，紧凑面包屑支持回跳，资源按三列显示。右下切角卡片仅含启停状态条、放大的缩略预览、名称和“切换键”按钮；点击卡片切换启停，点击“切换键”打开按键明细预览，点击缩略图独立打开预览。启用状态条使用强调色，切换时播放短动画并遵循减少动态效果设置。搜索、启停和弹窗仅操作内存预览数据，导航切换保留目录、搜索和启停状态。写回显示预览提示，“设置”跳转主设置页。
- 便捷构建：下载 / 构建 / 文件优化 / 自动化四张卡片在左侧纵向滚动，终端在右侧固定显示，圆环已取消。
- 设置：路径 / GIMI / 启动 / 缓存 / OMG；OMG 中可切换深色外观，输入 HEX 强调色并即时应用，或恢复默认 #39C5BB。强调色在主界面所有页面即时生效。
- 标题栏：window_manager 负责拖动、最小化、关闭；浅深主题均使用透明背景，等高线延伸到标题栏下方，构建页面切换时标题同步更新。透明底部导航和面包屑使用更紧凑的高度。

资源入口不再启动独立进程。首页保留资源浏览快捷入口，直接切到浏览页；旧 `--resources` 参数仅决定主界面的初始分页，所有导航仍可使用。
